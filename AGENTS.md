# Codex repository instructions

Read and follow `CLAUDE.md` as the canonical project guidance for architecture,
commands, testing, code quality, and contribution practices. References to Claude
or Claude Code in that file apply equivalently to Codex and other AI coding
assistants.

## Commits and pull requests

- Do not add AI attribution to commit messages or pull-request titles, bodies,
  or comments.
- Do not add `Co-Authored-By` trailers for Codex or any other AI assistant.
- Do not add phrases such as `Generated with Codex`, `Generated with Claude
  Code`, or similar signatures.
